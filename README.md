# APPLICATION WEB PORTFOLIO 

Ce repo contient tous les fichiers qui servent à faire tourner ma page web : portfolio. Contrairement, au repo "portefolio", la page est directement déployée sans passer par python flask 
et hébergée sur Github afin d'optimiser le temps de chargement et à terme, d'être référencé sur les moteurs de recherche. 

Le site web est un portfolio personnel dont l'objectif est de mettre en avant les différents projets que j'ai pu réaliser pendant mes études ainsi que les compétences que j'ai pu acquérir dans la data.
